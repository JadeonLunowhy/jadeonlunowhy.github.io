A **full-stack web application** for managing graduate school applications, from program discovery and document submission to application review and administrative management.

[**View on GitHub**](https://github.com/JadeonLunowhy/OAS)

### Highlights

- Designed a **role-based workflow** for students, admission officers, and administrators.
- Enabled students to browse and filter graduate programs, submit applications, and track application status.
- Implemented profile and document management for academic records, language scores, and application materials.
- Built admission officer tools for reviewing applications and managing applicant files.
- Developed administrator interfaces for managing universities, programs, and officer accounts.
- Structured the backend around **PHP APIs and a MySQL relational database** with session-based authentication.

### System Architecture

```text
Student / Admission Officer / Admin
                 |
                 v

       HTML · CSS · JavaScript
                 |
                 v

                 |
                 v

````

**Tech Stack:** PHP · MySQL · JavaScript · HTML/CSS · Apache · REST-style APIs
